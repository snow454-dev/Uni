# ウニ種苗 AI生産管理 システム（試作品）

エゾバフンウニ種苗生産センター向け **「AI画像解析・生産管理ダッシュボード」** の試作品Webアプリケーションです。

---

## 🌊 主な機能

1. **ホーム（生産管理ダッシュボード）**
   - 本日の解析件数、確認済み個体数、平均生残率、確認待ち件数、平均解析時間のKPI表示
   - 過去14日間の生残率推移グラフ、発育段階構成比、水槽別状況、アラート一覧
2. **撮影・解析**
   - 顕微鏡画像登録（ドラッグ＆ドロップ対応、サンプルプリセット付き）
   - 模擬AI解析（約1.5秒推論、生残率・着底率・信頼度算出、緑/赤/黄マーカー重畳表示）
   - 職員による数値修正・理由記録・確定保存
3. **確認待ち（目視判定キュー）**
   - AI信頼度80%未満・生残率85%未満のデータ抽出
   - 顕微鏡画像拡大・マーカー対話編集による目視判定
4. **水槽・ロット管理**
   - 飼育水槽（T-01〜T-05）の水温・塩分濃度・稼働状況
   - 受精ロット別推定個体数・着底率進捗
5. **分析・帳票**
   - 期間別・水槽別・発育段階別集計
   - 日本語文字化け防止（UTF-8 BOM付き）CSVダウンロード
   - A4横向き帳票印刷対応
6. **設定**
   - 警戒基準値・施設名・水槽マスタ設定
   - localStorage保存および初期サンプルデータ復元機能

## 🚀 開発・ローカル実行手順

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動 (ポート: 3000)
npm run dev

# プロダクションビルド
npm run build
```

## 🌐 GitHub / Web公開手順

### 1. GitHub へのエクスポート
- Google AI Studio 右上の **「Settings (設定)」** または **「Share (共有)」** メニューから **「Export to GitHub」** を選択します。
- 任意のリポジトリ名（例: `ezouni-ai-dashboard`）を指定して連携・プッシュします。

### 2. GitHub Pages での自動公開
このリポジトリには `.github/workflows/deploy.yml` が同梱されています。
1. GitHubリポジトリの **Settings** > **Pages** を開きます。
2. **Build and deployment** の **Source** を **「GitHub Actions」** に設定します。
3. `main` ブランチにプッシュされると自動ビルド＆デプロイされ、公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）でアクセス可能になります。
